# 建包与校对节点（C/X）模板

## 一、项目规则包（建包顺序）

1. 收集基准：设定总纲（最高依据）＋人物卡／设定文件＋剧情大纲；
2. 拆「层」：事实层（A/B）与写作层（D）分开——**D 层默认不读不判**（写作提醒/叙事功能/编排口径）；
3. 抽校对节点：按卷/节建 **C 节点**（每节 2—5 条检查点，标依据行号/版本）；跨卷线索建 **X 节点**（信物/物件谱系/知情链/时间线/红线/称谓/卷界等）；
4. 建四张断言表：人物属性表、时间线事实表、物件/线索流转表、规则表——每行带〔来源〕；
5. 建必填节点清单（N-XX）与确定性扫描清单；
6. 建精度勾选表（19 条）；
7. 声明判据与「不判错项」清单。

## 二、C 节点格式

```markdown
### C-01 <节名>（卷X §Y）
- 检查点 1：<事实/口径>（依据：总纲 Lxx；卡 Lxx）
- 检查点 2：…
- 检查点 3：…
```

## 三、X 节点格式

```markdown
### X-01 <跨卷线索名>
- 首现：Lxx（卷X §Y）
- 涉及：C-0x/C-0y
- 检查点：…
```

## 四、断言表模板

```markdown
### 表 1 人物属性表（N 行）
| 人物 | 身份/称谓 | 出生/年龄 | 经历/职业 | 关系 | 红线/灰度 〔来源〕 |
|---|---|---|---|---|---|
```

（提示：断言表要能"正向核对"——校验员逐行核对稿内是否落了该事实；未落标 ⚠，写反标 ❌。）

## 五、判据与不判错

- 事实冲突以设定总纲为最高依据；卡/合订本与总纲冲突时以总纲为准、不判编制件缺失。
- 创作留白、开放悬念、误传线索不判错；标注"基准未载明"处不得据以判错。
