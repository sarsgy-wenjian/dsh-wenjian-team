# 任务包速查（配合 roles/05-交接协议.md 使用）

| 编号 | 用途 | 主要派给 |
|---|---|---|
| A/B/C | 首检/复核/建议（按校对节点） | 01/02/03 |
| D | 定点修订（按用户勾选） | 04 |
| E/F/G | 规则包整理/校对/引导建包 | 06 |
| H | 拆块规划 | 07 |
| I | 设定增补建议 | 08 |
| J | 长文日常档（整稿不拆） | 01/02 |
| K | 长文定稿档（拆块＋跨块） | 07→01/02 |
| L | 语义专项第二遍（加严） | 01 |
| M | 误报降级/魔鬼辩护 | 01 fresh |
| N | 采样冗余（独立多轮取并集） | 01/02 |

## 通用模板

```text
【任务包 X】
① 待校验/待修订：<绝对路径，标版本>
② 基准：<项目规则包路径>（+ 设定文件 1—3 份）
③ 范围：全稿 / 第X—X卷 / 指定节
④ 模式：首检 / 复核 / 建议 / 修订 / 整理
⑤ 输出：按角色文件默认格式；结论标 blocking（是/否）；问题条目≤2 行
⑥ 特别关注：<本次重点，1—2 条>
```

## 门禁

- 结论必须标「是否 blocking」；复核输出「blocking 剩余 N 条」，N=0 才通过。
- 确认单逐条等作者勾选；未勾选不执行；修订后必须回 01 复核。
