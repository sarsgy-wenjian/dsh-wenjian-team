## Add dsh-wenjian-team

A manuscript-verification workflow for DSH.

- 10 skills: content checker, structure checker, revision advisor, doc reviser, handoff protocol, rulepack compiler, planner, setting augmenter, cost discipline, team lead.
- Host plugin deploys the skills to `$DSH_HOME/skills` and registers a `wenjian_team` tool (status/install/uninstall).
- No project data bundled; the plugin does not edit manuscripts.
- Internally measured on a 9k-character outline project: cost ¥3.781 → ¥2.559 (-32.3%), targeted recall 8/8, false positives 0.

Repo: https://github.com/sarsgy-wenjian/dsh-wenjian-team
